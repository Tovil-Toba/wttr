# 🌦️ wttr.app — Современный клиент сервиса погоды wttr.in

Современное веб-приложение (SPA) для мониторинга погоды в реальном времени, построенное на стеке **Angular 22 (Zoneless + Signals)**, **PrimeNG 22**, **Tailwind CSS** и официальном API консольного сервиса [wttr.in](https://wttr.in).

Проект спроектирован по стандартам **Feature-Based архитектуры** и принципам **Co-location**, оптимизирован для мгновенной загрузки, безупречной отзывчивости на любых экранах и поддержке светлой/тёмной тем оформления.

## ✨ Ключевые возможности

### 1. Текущая сводка погоды (Weather Hero)

- Отображение текущей температуры, показателя «Ощущается как», дневного максимума и минимума.
- **Динамическая тема оформления:** фон карточки, акцентные градиенты и иконка автоматически меняются в зависимости от погодных условий (солнечно, дождь, гроза, снег, туман, переменная облачность и т.д.).
- **7 ключевых метеорологических метрик** в адаптивном flexbox-контейнере:
  - Влажность воздуха (%)
  - Скорость и 16-румбовое направление ветра (С, СВ, Ю, З и т.д.)
  - Атмосферное давление (мм рт. ст. или гПа)
  - UV-индекс с цветовым индикатором опасности (Низкий, Умеренный, Высокий, Экстремальный)
  - Процент облачности (%)
  - Количество осадков (мм)
  - Дальность видимости (км)
- Добавление текущего города в «Избранное» в один клик.

### 2. Почасовой прогноз (Hourly Forecast)

- Сводка каждые 3 часа на 3 дня вперёд (температура, ощущение, влажность, скорость ветра, погодные иконки).
- Плавный горизонтальный скроллер с кнопками навигации и плавным скрытием стрелок в крайних положениях.
- Защита от случайного срабатывания тултипов с задержкой появления `[showDelay]="500"`.

### 3. Прогноз на 3 дня и Астрономия (Daily Forecast)

- Карточки прогноза по дням: «Сегодня», «Завтра», «Послезавтра» с полной датой на русском языке.
- Дневные температурные диапазоны и дневные погодные условия.
- Астрономический блок: время восхода и захода Солнца, фаза Луны с описанием на русском языке (Новолуние, Растущий полумесяц, Полнолуние и т.д.) и временем захода Луны.

### 4. Избранные города и Быстрые пресеты

- Быстрый выбор популярных городов в шапке (Обнинск, Москва, Санкт-Петербург, Сочи, Казань, Новосибирск, Владивосток, Лондон, Токио, аэропорт Шереметьево SVO).
- Персональный список избранных городов с сохранением в `localStorage`.
- Поиск по названию населенного пункта на любом языке, IATA-коду аэропорта (например, `SVO`, `LED`, `MUC`) или географическим координатам.
- Определение местоположения в один клик через браузерный Geolocation API с безопасным fallback-определением.

### 5. Консольные фичи wttr.in (Wttr Features)

- **WEB версия (HTML):** интерактивный предпросмотр веб-страницы отчёта wttr.in внутри изолированного HTML-фрейма с адресной строкой, кнопкой копирования ссылки и переходом на оригинал.
- **Терминал (ANSI/curl):** готовая команда для вызова в bash/cmd/PowerShell с подсветкой, кнопкой копирования в буфер обмена и исходным выводом данных.
- **Генератор PNG-виджетов:** предпросмотр и ссылка на графический баннер с поддержкой прозрачности (`_t`), рамки (`_p`) и отображения только текущей сводки (`_0`).
- **Однострочный режим (One-line format):** конфигуратор вывода для статус-баров (i3blocks, polybar, tmux, waybar) с форматами `%c%t`, `%c %t %w`, полным текстом и кастомными флагами.

### 6. Премиальный дизайн и темы

- Темная и светлая темы с моментальным переключением без мерцания (Zero FOUC скрипт в `index.html`).
- Эстетика Glassmorphism (`backdrop-blur-xl`, полупрозрачные границы `border-white/20`, мягкие тени).
- Фирменный логотип с плавной микроанимацией при наведении.

## 📂 Архитектура проекта

Проект организован по **Feature-Based структуре** в соответствии с официальным [Angular Style Guide](https://angular.dev/style-guide) и принципом **Co-location** (файлы, меняющиеся вместе, хранятся вместе):

```text
src/
├── app/
│   ├── core/                                 # Глобальные сервисы и синглтоны уровня приложения
│   │   └── theme.service.ts                  # Сервис переключения и сохранения темы (Light/Dark)
│   │
│   ├── layout/                               # Структурные компоненты разметки приложения
│   │   └── navbar/                           # Навигационная панель, поиск, настройки, темы
│   │       ├── navbar.html
│   │       ├── navbar.scss
│   │       └── navbar.ts
│   │
│   ├── features/                             # Бизнес-домены приложения
│   │   ├── weather/                          # Домен погоды
│   │   │   ├── weather.model.ts              # Модели данных wttr.in, интерфейсы ответов
│   │   │   ├── weather.service.ts            # Сервис данных, стейт на Сигналах, API-вызовы
│   │   │   ├── weather-hero/                 # Главная карточка текущего состояния и метрик
│   │   │   ├── hourly-forecast/              # Горизонтальный скроллер почасового прогноза
│   │   │   ├── daily-forecast/               # 3-дневный прогноз и астрономический блок
│   │   │   └── wttr-features/                # Терминал (curl), PNG и однострочные форматы
│   │   │
│   │   └── favorites/                        # Домен избранных локаций
│   │       └── favorites-list/               # Список сохранённых городов
│   │
│   ├── app.config.ts                         # Конфигурация приложения (Zoneless, HttpClient, PrimeNG)
│   ├── app.html                              # Главный шаблон приложения
│   ├── app.scss                              # Корневые стили приложения
│   ├── app.spec.ts                           # Базовые тесты рендеринга и инициализации
│   └── app.ts                                # Корневой компонент
│
├── public/                                   # Статические ассеты (логотип logo.jpg, favicon)
├── styles.scss                               # Глобальные стили, директивы Tailwind, шрифты
├── index.html                                # Точка входа HTML с FOUC-скриптом предотвращения мигания темы
└── main.ts                                   # Загрузчик Angular (bootstrapApplication)
```

### Архитектурные правила проекта:

1. **Zoneless & OnPush:** приложение работает в режиме `provideZonelessChangeDetection()`. Все компоненты полагаются на сигналы (`signal`, `computed`, `effect`), а Angular 22 по умолчанию применяет стратегию `OnPush` ко всем компонентам без лишнего шаблонного кода.
2. **Безопасная работа с DOM и Web API:** глобальные браузерные объекты (`window`, `localStorage`, `navigator`) не вызываются напрямую — обращение к ним выполняется строго через `this.document.defaultView` с внедрением токена `inject(DOCUMENT)`.
3. **Прямые Standalone-импорты:** вместо тяжелых модулей (`TagModule`, `TooltipModule`) используются direct standalone компоненты/директивы (`Tag`, `Tooltip`), что уменьшает размер финального бандла.

## 🚀 Быстрый старт и установка

### Системные требования

- **Node.js:** версия `v18.13.0` или выше (рекомендуется `v20.x` или `v22.x`).
- **npm:** версия `9.x` или выше.

### Шаги установки

1. **Клонируйте репозиторий или перейдите в папку проекта:**

   ```bash
   cd wttr
   ```

2. **Установите зависимости проекта:**

   ```bash
   npm install
   ```

3. **Запустите локальный сервер разработки:**

   ```bash
   npm start
   ```

4. **Откройте приложение в браузере:**
   Перейдите по адресу: [http://localhost:4200](http://localhost:4200)

Сервер поддерживает горячую перезагрузку (Hot Module Replacement) — любые изменения в исходных кодах мгновенно отображаются на экране.

## ⚙️ Настройки и кастомизация

В приложении предусмотрена всплывающая панель настроек единиц измерения в шапке (иконка слайдеров 🎛️):

| Параметр           | Доступные варианты               | По умолчанию           | Описание                                                  |
| :----------------- | :------------------------------- | :--------------------- | :-------------------------------------------------------- |
| **Температура**    | `°C` (Цельсий), `°F` (Фаренгейт) | `°C`                   | Пересчёт отображается во всех компонентах                 |
| **Скорость ветра** | `м/с`, `км/ч`, `mph`             | `м/с`                  | Автоматическая конвертация `windspeedKmph`                |
| **Давление**       | `мм рт. ст.`, `гПа`              | `мм рт. ст.`           | Конвертация гектопаскалей в миллиметры ртутного столба    |
| **Тема**           | `Dark`, `Light`                  | `Dark` (или системная) | Синхронизируется с атрибутом `class="dark"` тега `<html>` |

Все пользовательские настройки, избранные города и история поиска автоматически сохраняются в `localStorage` и восстанавливаются при следующем входе.

## 🌐 Взаимодействие с wttr.in API

Приложение обращается к публичному API сервиса [wttr.in](https://wttr.in):

- **JSON-прогноз:**  
  `GET https://wttr.in/{query}?format=j1&lang=ru`  
  Возвращает подробный JSON со сводкой текущей погоды (`current_condition`), 3-дневным прогнозом (`weather`) и информацией о местности (`nearest_area`).
- **Консольный режим (curl):**  
  `curl 'wttr.in/{query}?lang=ru'`
- **Графический PNG-баннер:**  
  `https://wttr.in/{query}_{options}.png`  
  Параметры: `t` (прозрачный фон), `p` (рамка), `0` (только текущая погода).
- **Однострочный режим:**  
  `curl 'wttr.in/{query}?format={formatIndex}&lang=ru'`

## 🤖 Интеграция Model Context Protocol (MCP)

В проекте настроены два MCP-сервера для взаимодействия с интеллектуальными ассистентами и инструментами разработки:

1. **`angular-cli` MCP Server:**
   - Анализ рекомендаций архитектуры Angular 22 (`get_best_practices`)
   - Поиск по актуальной документации (`search_documentation`)
   - Поиск примеров кода (`find_examples`)

2. **`@primeng/mcp` Server:**
   - Валидация использования компонентов PrimeNG (`validate_usage`)
   - Документация и руководства по настройке компонентов (`get_component`, `get_guide`, `get_setup`)
   - Получение примеров использования (`get_example`)

Конфигурации серверов зарегистрированы в [.antigravity/mcp.json](file:///g:/projects/angular/agy-test/wttr/.antigravity/mcp.json) и [.agents/mcp_config.json](file:///g:/projects/angular/agy-test/wttr/.agents/mcp_config.json).
