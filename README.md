Современное одностраничное веб-приложение (SPA) для мониторинга погоды в реальном времени, построенное на стеке **Angular 22 (Zoneless + Signals)**, **PrimeNG 22**, **Tailwind CSS** и официальном API консольного сервиса [wttr.in](https://wttr.in).

Проект спроектирован по стандартам **Feature-Based архитектуры** и принципам **Co-location**, оптимизирован для мгновенной загрузки, безупречной отзывчивости на любых экранах, интеллектуальной мультиязычности и бесшовной смены светлой/тёмной тем оформления.

> [!NOTE]
> **Манифест разработки:** проект создан в открытом тандеме человека и автономного ИИ-ассистента в среде **Google Antigravity** (команда _Advanced Agentic Coding в Google DeepMind_) под управлением флагманской когнитивной модели **Gemini**. Вся архитектура — от реактивного стейта на Сигналах и системы i18n до отказоустойчивых HTTP-запросов и 100% покрытия тестами — разрабатывалась методом непрерывного парного агентного программирования (_AI Pair Programming / вайб-кодинг_) под кураторством автора.

## ✨ Ключевые возможности

### 1. Текущая сводка погоды (Weather Hero)

- Отображение текущей температуры, показателя «Ощущается как», дневного максимума и минимума.
- **Динамическая тема оформления:** фон карточки, акцентные градиенты и погодная SVG-иконка автоматически адаптируются под погодные условия (солнечно, дождь, гроза, снег, туман, переменная облачность и т.д.) с учетом времени суток (день/ночь).
- **7 ключевых метеорологических метрик** в адаптивном flexbox-контейнере:
  - Влажность воздуха (%)
  - Скорость и 16-румбовое направление ветра (С, СВ, Ю, З и т.д.)
  - Атмосферное давление (мм рт. ст. или гПа)
  - UV-индекс с цветовым индикатором опасности (Низкий, Умеренный, Высокий, Экстремальный)
  - Процент облачности (%)
  - Количество осадков (мм)
  - Дальность видимости (км)
- Добавление текущего города в «Избранное» в один клик с мгновенной анимацией звёздочки.

### 2. Почасовой прогноз (Hourly Forecast)

- Сводка с 3-часовым шагом на 3 дня вперёд (температура, ощущение, влажность, скорость ветра, погодные иконки, вероятность осадков).
- Плавный горизонтальный скроллер с кнопками навигации и мягким скрытием стрелок в крайних положениях.
- Защита от случайного срабатывания тултипов с задержкой появления `[showDelay]="500"`.

### 3. Прогноз на 3 дня и Астрономия (Daily Forecast)

- Карточки прогноза по дням: «Сегодня», «Завтра», «Послезавтра» с полной локализованной датой.
- Дневные температурные диапазоны и дневные погодные условия.
- Астрономический блок: время восхода и захода Солнца в 24-часовом формате, фаза Луны с описанием на выбранном языке (Новолуние, Растущий полумесяц, Полнолуние и т.д.) и процентом освещённости.

### 4. Избранные города и Быстрые пресеты

- Быстрый выбор популярных городов в шапке (Обнинск, Москва, Санкт-Петербург, Сочи, Казань, Новосибирск, Владивосток, Лондон, Токио, аэропорт Шереметьево SVO) с автоматическим переводом названий на язык интерфейса.
- Персональный список избранных локаций с сохранением в `localStorage`.
- Поиск по названию населенного пункта на любом языке, IATA-коду аэропорта (например, `SVO`, `LED`, `MUC`) или географическим координатам.
- Определение местоположения в один клик через браузерный Geolocation API с безопасным fallback-определением.

### 5. Консольные фичи wttr.in (Wttr Features)

- **WEB версия (HTML):** интерактивный предпросмотр веб-страницы отчёта wttr.in внутри изолированного HTML-фрейма с адресной строкой, кнопкой копирования ссылки и переходом на оригинал.
- **Терминал (ANSI/curl):** готовая команда для вызова в bash/cmd/PowerShell с подсветкой, кнопкой копирования в буфер обмена и выводом оригинального ASCII-арта.
- **Генератор PNG-виджетов:** предпросмотр и ссылка на графический баннер с поддержкой прозрачности (`_t`), рамки (`_p`) и отображения только текущей сводки (`_0`), а также готовым кодом для вставки в HTML/Markdown.
- **Однострочный режим (One-line format):** конфигуратор вывода для статус-баров (i3blocks, polybar, tmux, waybar) с форматами `%c%t`, `%c %t %w`, полным текстом и кастомными флагами.

### 6. Модальные окна справки и информации о проекте

- **Справка (Instructions Modal):** подробное руководство пользователя с 4 тематическими разделами (базовое использование, настройки и темы, фичи API, шпаргалка команд `curl` с копированием в один клик).
- **О проекте (About Modal):** манифест разработки с Antigravity и Gemini, интерактивная витрина стека технологий, информация об авторе и первоисточнике API.

### 7. Премиальный дизайн и адаптивность

- Тёмная и светлая темы с переключением без мерцания (Zero FOUC скрипт в `<head>` [index.html](file:///g:/projects/angular/agy-test/wttr/src/index.html)).
- Автоматическая адаптация под системную тему ОС (`prefers-color-scheme`) при первом открытии с возможностью фиксации выбора пользователем.
- Эстетика Glassmorphism (`backdrop-blur-xl`, полупрозрачные границы `border-white/20`, мягкие тени).
- Фирменный логотип с автоматическим переключением вариантов (`logo-dark.jpg` / `logo-light.jpg`) и синхронизацией динамического favicon и тегов `color-scheme`.

## 🌍 Интернационализация (i18n) и автоопределение

В приложении реализован собственный легковесный реактивный движок локализации без сторонних тяжёлых библиотек:

- **12 поддерживаемых языков:**
  - 🇷🇺 Русский (`ru`)
  - 🇬🇧 English (`en`)
  - 🇩🇪 Deutsch (`de`)
  - 🇪🇸 Español (`es`)
  - 🇫🇷 Français (`fr`)
  - 🇮🇹 Italiano (`it`)
  - 🇧🇷 Português (BR) (`pt-br`)
  - 🇹🇷 Türkçe (`tr`)
  - 🇨🇳 简体中文 (`zh-cn`)
  - 🇯🇵 日本語 (`ja`)
  - 🇧🇾 Беларуская (`be`)
  - 🇰🇿 Қазақша (`kk`)

- **Интеллектуальное определение языка системы клиента:**
  1. При первом визите опрашиваются системные настройки браузера (`navigator.languages` и `navigator.language`).
  2. Поддерживаются сопоставления региональных кодов (например, `en-US` $\rightarrow$ `en`, `de-AT` $\rightarrow$ `de`, `pt-BR` $\rightarrow$ `pt-br`).
  3. Для неподдерживаемых языков предусмотрен безопасный fallback на русский язык (`ru`).
  4. При ручном выборе языка в меню шапки выбор сохраняется в `localStorage['wttr_lang']` и получает безусловный приоритет.

- **Глубокая интеграция с wttr.in:**
  - Параметр выбранного языка `&lang={code}` автоматически пробрасывается во все исходящие запросы к API: в JSON-прогноз, фрейм веб-версии, консольные команды `curl`, ссылки на PNG-инфографику и однострочники.

- **Умный перевод погодных условий (Weather Description):**
  - Сервис автоматически определяет случаи, когда upstream API `wttr.in` возвращает английскую заглушку для неподдерживаемых погодных кодов, и на лету подставляет корректный перевод из встроенного локального словаря (например, _«Patchy rain nearby»_ $\rightarrow$ _«Местами кратковременный дождь»_).

- **Динамическая локализация географических названий:**
  - Названия стран, городов в карточке, в блоке быстрого выбора и в списке «Избранное» динамически переводятся в зависимости от текущего языка интерфейса.

- **Локализация дат:**
  - Все дни недели и месяцы форматируются через нативный `Intl.DateTimeFormat` с генерацией правильных языковых окончаний и падежей.

- **Синхронизация HTML-разметки:**
  - Атрибут `document.documentElement.lang` мгновенно обновляется при смене языка, улучшая доступность (a11y) и экранные ридеры.

### Архитектурные правила проекта:

1. **Zoneless & OnPush:** приложение работает в режиме `provideZonelessChangeDetection()`. Все компоненты полагаются на сигналы (`signal`, `computed`, `effect`), а Angular 22 по умолчанию применяет стратегию `OnPush` ко всем компонентам без лишнего шаблонного кода.
2. **Безопасная работа с DOM и Web API:** глобальные браузерные объекты (`window`, `localStorage`, `navigator`, `document`) не вызываются напрямую — обращение к ним выполняется строго через `this.document.defaultView` с внедрением токена `inject(DOCUMENT)`.
3. **Прямые Standalone-импорты:** вместо тяжелых модулей используются прямые standalone-компоненты и директивы, что снижает размер итогового бандла.
4. **Собственный i18n движок с каскадным Fallback:** при запросе ключа локализации, отсутствующего в частичных словарях, движок автоматически откатывается на английский или русский базовый словарь без выброса ошибок в рантайме.

## 🚀 Быстрый старт и установка

### Системные требования

- **Node.js:** версия `v18.13.0` или выше (рекомендуется `v20.x` или `v22.x`).
- **npm:** версия `9.x` или выше.

### Шаги установки

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/Tovil-Toba/wttr.git
   cd wttr
   ```

2. **Установите зависимости проекта:**

   ```bash
   npm install
   ```

3. **Запустите локальный сервер разработки:**

   ```bash
   npm start
   ```

4. **Откройте приложение в браузере:**
   Перейдите по адресу: [http://localhost:4200](http://localhost:4200)

Сервер поддерживает горячую перезагрузку (Hot Module Replacement) — любые изменения мгновенно отображаются на экране.

| **Температура**    | `°C` (Цельсий), `°F` (Фаренгейт)    | `°C`                 | Пересчёт отображается во всех компонентах                                   |
| **Скорость ветра** | `м/с`, `км/ч`, `mph`                | `м/с`                | Автоматическая конвертация `windspeedKmph`                                  |
| **Давление**       | `мм рт. ст.`, `гПа`                 | `мм рт. ст.`         | Конвертация гектопаскалей в миллиметры ртутного столба                      |
| **Тема**           | `Dark`, `Light`                     | Системная (или Dark) | Синхронизируется с системными настройками ОС и сохраняется в `localStorage` |
| **Язык**           | 12 языков (RU, EN, DE, ES, FR, ...) | Системный (или RU)   | Мгновенно переводит UI и передается во все запросы wttr.in                  |

Все пользовательские настройки, избранные города и история поиска автоматически сохраняются в `localStorage` и восстанавливаются при следующем входе.

## 🌐 Взаимодействие с wttr.in API и отказоустойчивость

Приложение обращается к публичному API сервиса [wttr.in](https://wttr.in):

- **JSON-прогноз:**  
  `GET https://wttr.in/{query}?format=j1&lang={lang}`  
  Возвращает подробный JSON со сводкой текущей погоды (`current_condition`), 3-дневным прогнозом (`weather`) и информацией о местности (`nearest_area`).
- **Консольный режим (curl):**  
  `curl 'wttr.in/{query}?lang={lang}'`
- **Графический PNG-баннер:**  
  `https://wttr.in/{query}_{options}.png?lang={lang}`  
  Параметры: `t` (прозрачный фон), `p` (рамка), `0` (только текущая погода).
- **Однострочный режим:**  
  `curl 'wttr.in/{query}?format={formatIndex}&lang={lang}'`

### Двухконтурная отказоустойчивость (Failover):

Если основной сервер `https://wttr.in` временно недоступен или возвращает ошибку, сервис автоматически и прозрачно для пользователя переключает запрос на резервное зеркало **`https://wttr.is`**.

## 🤖 Интеграция Model Context Protocol (MCP)

В проекте настроены два MCP-сервера для взаимодействия с интеллектуальными ассистентами и инструментами разработки:

1. **`angular-cli` MCP Server:**
   - Анализ рекомендаций архитектуры Angular 22 (`get_best_practices`)
   - Поиск по актуальной документации (`search_documentation`)
   - Поиск примеров кода (`find_examples`)

2. **`@primeng/mcp` Server:**
   - Валидация использования компонентов PrimeNG (`validate_usage`)
   - Документация и руководства по настройке компонентов (`get_component`, `get_guide`, `get_setup`)
   - Получение примеров использования (`get_example`)

Конфигурации серверов зарегистрированы в [.antigravity/mcp.json](file:///g:/projects/angular/agy-test/wttr/.antigravity/mcp.json) и [.agents/mcp_config.json](file:///g:/projects/angular/agy-test/wttr/.agents/mcp_config.json).
